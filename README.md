# 공리적 시학 3D 시각화: 사랑의 끌개장

이 프로젝트는 김언 「사랑」의 14개 구절에 부여한 `y`, `z`, `m`, `p`, `s`, `e`, `a` 값을 기반으로 생성되는 3D 시각화입니다. 핵심 목표는 기존의 로런츠 끌개 같은 외부 수학 모형을 차용하지 않고, **시 텍스트 내부의 판정값이 직접 끌개장, 독자 의미 배열 접힘, 귀환 매듭, 자유도 기반 튜브 반지름을 생성하게 하는 것**입니다.

> 모든 곡선은 임의로 그리지 않고, 공리적 끌개장 안에서 생성됩니다.

## 구현된 핵심 기능

| 기능 | 구현 방식 | 이론적 의미 |
|---|---|---|
| 구절 궤도 | 14개 구절의 `id`, `y`, `z` 값을 3D 좌표로 변환 | 시의 전개가 하나의 궤도로 나타남 |
| 자유도 튜브 | `F = 1.2(1-y)+0.18e+0.16a+0.12s-0.14p`를 반지름으로 변환 | 독자 해석 가능성이 넓을수록 튜브가 두꺼워짐 |
| 공리적 끌개 | 4, 7, 9, 11, 14번 구절을 중심으로 끌개장 생성 | 부재, 공리 현존, 양의 도약, 급락, 침묵의 중심 |
| 단백질 접힘 | 여러 독자 seed 곡선이 끌개장 안에서 이동 | 독자 의미 배열이 텍스트 경관 위에서 다르게 접힘 |
| 귀환 매듭 | 14번에서 1번으로 돌아가는 선이 끌개장에 의해 휘어짐 | 끝이 처음을 다시 변형시키는 재독 구조 |
| z=0 기준면 | 반투명 기준면으로 양/음 정동 영역 구분 | 양의 발현과 음의 침잠의 기하학적 분리 |

## GitHub Pages에 올리는 방법

가장 단순한 방식은 이 폴더 안의 파일을 GitHub 저장소 루트에 그대로 업로드하는 것입니다. 저장소 이름이 예를 들어 `axiomatic-poetics-3d`라면, `index.html`이 저장소 최상위에 있어야 합니다.

GitHub에서 저장소를 만든 뒤 다음 명령을 사용할 수 있습니다.

```bash
git init
git add .
git commit -m "Add axiomatic poetics 3D visualization"
git branch -M main
git remote add origin https://github.com/사용자명/저장소명.git
git push -u origin main
```

그다음 GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택하고, `main` 브랜치의 `/root`를 지정하면 됩니다.

## 값 수정 위치

구절 데이터는 `src/app.js`의 맨 위 `versePoints` 배열에 들어 있습니다. 나중에 값이나 구절을 바꾸고 싶으면 이 배열만 수정하면 됩니다.

```js
{ id: 1, text: '그건 내게 없는 것이었다', y: 0.58, polarity: -1, m: 3, p: 0, s: 4, e: 5, a: 0, z: -2.63, label: '부재의 선언 (공리 세팅)' }
```

공리적 끌개로 강조할 구절은 아래 배열에서 조정할 수 있습니다.

```js
const AXIOM_ATTRACTOR_IDS = [4, 7, 9, 11, 14];
```

## 로컬에서 확인하는 방법

브라우저 보안 정책 때문에 `file://`로 직접 열기보다 간단한 로컬 서버를 사용하는 것이 좋습니다. 프로젝트 폴더에서 다음 명령을 실행하면 됩니다.

```bash
python3 -m http.server 8080
```

그다음 브라우저에서 `http://localhost:8080`으로 접속하면 됩니다.

## 설계상 중요한 점

이 시각화는 완성된 논문용 도식이라기보다, 공리적 시학의 모델을 검증하고 발표하기 위한 프로토타입입니다. 따라서 다음 단계에서 더 정밀하게 발전시킬 수 있습니다. 첫째, 독자 의미 배열 seed를 실제 독자 반응 데이터로 대체할 수 있습니다. 둘째, 끌개 중심을 현재처럼 4, 7, 9, 11, 14번으로 고정하지 않고 강도 공식에 따라 자동 산출할 수 있습니다. 셋째, 귀환 매듭의 교차 지점을 실제 궤도와의 거리 계산으로 판정하게 만들 수 있습니다.

현재 버전의 핵심 성과는 명확합니다. **로런츠 끌개를 제거하고, 시의 내부 좌표값에서 공리적 기하학이 발생하도록 구조를 바꾼 것**입니다.
